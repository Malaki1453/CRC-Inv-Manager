# Cast Right Catch Inventory

**[Download installer (CRC-Inventory-Setup.msi)](https://github.com/Malaki1453/CRC-Inv-Manager/releases/latest/download/CRC-Inventory-Setup.msi)**

That link always downloads the newest installer. Run it on Windows, then open **Cast Right Catch Inventory** from the Start Menu.

If the link 404s, the MSI has not been attached to a GitHub Release yet. Create a release named `v1.0.0`, upload `CRC-Inventory-Setup.msi`, and the button will work.

Installed copies check GitHub on launch and force-install a newer release when one exists.
